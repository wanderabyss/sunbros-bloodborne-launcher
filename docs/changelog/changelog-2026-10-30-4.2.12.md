# 4.2.12 — The repository is now sunbros-bloodborne-launcher (2026-10-30)

Built on 4.2.11. The game and the launcher behave the same; only the repository address changes.

## Why

The public repository was renamed from wanderabyss/sunbros_bblauncher to wanderabyss/sunbros-bloodborne-launcher, so a search for "bloodborne" on GitHub finds it by name.

## What changed

- `launcher/bbport_launcher_win.py`: `RELEASES_API` and `RELEASES_PAGE` use the new name, and with them the update check and download, Settings > Releases, and the update sheet's links. `run.py`'s `RELEASES` changes too.
- `tests/test_update_download_qml.py`: the new addresses.

## Checked

- The Python suite passes.
- The old API address (what 4.2.9 to 4.2.11 ask for) redirects: from Python's urllib, as the launcher calls it, it answers 200 with the latest release and a zip link under the new name.
