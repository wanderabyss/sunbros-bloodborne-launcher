# Changelog — October 28, 2026

## 3.3.2 — HD Texture Pack setup fix

- The launcher builds the HD Texture Pack by itself once every Nexus download is in its downloads folder and no pack is built: when its window opens, after a downloads folder is chosen with Browse, or when the last download arrives from the browser's Downloads folder. It does not build while the game runs.
- Browse beside the HD Texture Pack folder and the HD Texture Pack downloads folder opens a folder picker; before, those two rows ignored the click.
- Without a chosen downloads folder, an `hd-pack-downloads` folder beside the launcher's folder is used when the pack's own `downloads` folder is missing.
- `tests/test_launcher_hd_indicator.py` covers the folder beside the launcher and the automatic build; its 8 tests pass. Version metadata advances to 3.3.2; the package is `bbport-windows-3.3.2.zip`.

### Known issue found while testing

A launcher whose settings file still names folders from an older install (saves, mods) keeps using them: the 3.3.x launcher reads `%APPDATA%\bbport-launcher\settings.json` and the `bbport_settings.json` copies in the saves and game folders. Check the saves folder in Settings after upgrading from an older install.
