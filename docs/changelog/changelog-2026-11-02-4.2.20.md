# 4.2.20 — DLSS 5 setup: the launcher spots ReShade's standard build (2026-11-02)

## Why

Players followed the DLSS 5 guide and got no DLSS 5. One player's logs (RTX 4090, 60 FPS, DLSS upscaler) showed every check the port makes passing: the game logged `DLSS 5: on (community bridge)` and `DLSS 5: running`. Their `bin\ReShade.log` showed the cause: `Skipped loading add-on ... because this build of ReShade has only limited add-on functionality`, for both `dlss5-bridge.addon64` and `renodx-dlss5.addon64`. They had installed ReShade's standard build, and nothing in the port could say so. The guide also understated the requirements: it read as any RTX 40 or 50 card, and it called 60 FPS a warning.

## What changed

**Launcher** (`bloodborne_pc/launcher/bbport_launcher_win.py`)
- `reshade_addons_skipped()` reads the last start's `bin\ReShade.log` for "only limited add-on functionality". Read only; no log, no warning.
- `neural_runtime_text()` (the DLSS 5 status line) and `dlss5_fps_warning()` (the start log and the DLSS 5 row's hint) then say to install ReShade "with full add-on support". The next start rewrites the log, so the warning goes once the right build is installed.
- The game itself still reports "DLSS 5: on": before the start nothing tells ReShade's builds apart, so `run.py` keeps its checks as they were.

**Game messages**
- `vk_temporal_upscaler.cpp`: a card offered DLSS 5 whose DLSS did not load logs `DLSS 5: not offered (DLSS did not load; <GPU>)`. It said "(this GPU; NVIDIA GeForce RTX 4090)".
- `bbport_settings.cpp` `Dlss5Unavailable`: with no DLSS 5 backend the in-game menu says to switch DLSS 5 on in the launcher. It said the community bridge was paused, which has not been true since 4.0.0: `run.py` sets up the route only for a start with `dlss5=on`.

**Guide** (`docs/dlss5-setup.md`)
- Cards: desktop RTX 4080, 4080 SUPER, 4090, 4090 D and RTX 5070 Ti or faster (`BbDlss5Eligible`); not RTX 4060/4070, 5060/5070, laptops or workstation cards.
- 60 FPS is a requirement; the launcher is the only way to switch DLSS 5 on.
- ReShade "with full add-on support" is a separate download from the main button.
- Troubleshooting rows: the standard ReShade build, the "not offered" reasons, 60 FPS, and F2 vs Home for the overlay.
