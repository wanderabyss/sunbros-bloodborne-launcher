# 4.2.10 — Check now answers on the Updates page (2026-10-30)

Built on 4.2.9. Launcher only; no game or renderer changes.

## Why

Pressing **Check now** in Settings > Updates looked like it did nothing. `checkForUpdates` sent its answer through `workerNotice`, which sets the launcher notice that only the Home page shows. The Updates card shows `updateStatus`, which only the update download wrote to.

## What changed

- `launcher/bbport_launcher_backend.py` `checkForUpdates`: a manual check sets the card's status to "Checking for updates…" straight away (unless a download is running), then writes its answer to both `updateStatus` (the Updates card) and the notice (Home): you have the latest version, version X is available, no published release was found, or why the check failed. The quiet check at start is unchanged.
- `tests/test_update_download_qml.py`: `test_check_now_answers_in_the_updates_card` covers the four answers.

## Checked

- The Python suite passes (513).
- In the 4.2.10 launcher: Check now shows the answer under the switches ("Could not find a published release to compare with (you have 4.2.10).", as expected while the release repository is private).

While wanderabyss/sunbros_bblauncher is private, every check ends with "Could not find a published release to compare with": the launcher asks GitHub without signing in.
