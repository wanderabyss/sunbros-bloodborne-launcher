# 4.2.5 — First start set for your PC (2026-10-30)

Built on 4.2.4. Launcher only; no game or renderer changes.

## Why

`INI_DEFAULTS` in `launcher/bbport_launcher_win.py` describes one machine: `output_res=3840x2160` and `upscaler=dlss`. A new install with no `bbport.ini` and no saved settings used those as they were, so a 1080p display started at 4K output, and an AMD or Intel card started with an upscaler it can't run.

## What changed

- `bbport_launcher_win.py`: `first_start_settings(gpu, display)` returns the output resolution from the primary display (physical pixels, within 256 × 144 – 7680 × 4320), `upscaler=dlss` on an NVIDIA RTX card and `fsr3` otherwise, and the preset `recommended_graphics_preset` suggests.
- `bbport_launcher_backend.py`: `LauncherBackend` notes a first start (no `bbport.ini` and no saved `ini_settings`). When the GPU check first reports (`_set_gpu_status`), `_apply_first_start` applies those values and the preset, writes `bbport.ini` and the launcher settings once, and sets `firstStartSummary` ("Set for your PC: NVIDIA GeForce RTX 4090, 3840 × 2160, Remastered. Change anything you like."). Later reports, and later starts, change nothing.
- `SetupWizard.qml` shows the summary above the preset description.
- Tests: `tests/test_graphics_presets.py` (RTX 4090, Radeon RX 7900 XTX, GTX 1060, no GPU answer, an out-of-range display), `tests/test_depth_workspaces_qml.py` (first report applies, a second doesn't). The shared QML fixture (`test_home_dashboard_qml.py`) turns the first start off and stubs `save_ini`, so a checkout without `bbport.ini` writes nothing.
