# 4.2.21 — NG+7 world: full NG+7 enemies from the first beast, every Caryll Rune (2026-11-06)

## Why

A player wanted to finish the game at its highest difficulty without playing it eight times, with everything unlocked.

## What the game does

- `GameDataMan` +0x68 is the NG cycle, 0..7 (`AddClearCount` and the ending clamp it).
- `NpcParam.GameClearSpEffectID` gives each enemy a SpEffect holding its NG+1 multipliers. Rows with `bGameClearBonus` are scaled by a table indexed with the counter, clamped to 6: `0, 1, 1.07, 1.1, 1.125, 1.15, 1.2` (image 0x4731ed0) and, for echoes, `0, 1, 1.1, 1.25, 1.5, 2, 2.5` (0x4731ef0). So NG+6 and NG+7 are the same strength.
- About 70 sites read the counter live. No event file uses its condition (3[17]), and no Lua script names it. The only event use is the ending's add (2003[21]).

## What changed

**Runtime** (`bloodborne_pc/src/ng_plus.c`, `BB_PC_NG7_ACTIVE`)
- The live counter stays at 7: the save load and a new game's clear are hooked, and a main-thread tick covers the rest. It leaves the counter alone in another player's world (session +0x1598).
- The save writer gets the character's real cycle, and the ending's add raises it, so the switch is reversible.
- All four hooks check the code they replace; if one is refused, the feature stays off and the save is untouched.

**Rune gift** (`bloodborne_pc/scripts/enhancements.py`, `pc_ng_plus_7`, folder `ng-plus-7`)
- New event 12100970 in `m21_00_00_00.emevd`, flag 12100971: awards 27 item lots (best tier of 21 runes, 6 oath runes), each a single certain gem with its own flag. Input and output are checked by SHA-256.

**Switch:** launcher (`ENHANCEMENTS`), overlay (`bbport_settings.h`), `BB_PC_NG7`, `run.py`, `run.sh`, README.

## Tests

- `tests/test_enhancements.py`: the switch stays off by default; on the real game, the event gives each lot once and every lot is one certain rune with a flag.
