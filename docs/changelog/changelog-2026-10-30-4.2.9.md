# 4.2.9 — Updates from the new repository; GPL v3 licence files (2026-10-30)

Built on 4.2.8. Launcher and docs only; no game or renderer changes.

## Why

SunBro's Edition moves to a new repository, wanderabyss/sunbros_bblauncher, which carries the complete source next to the releases. A package checks for updates at the address it was built with, so 4.2.8 and earlier keep asking the old repository; 4.2.9 is the first build that asks the new one.

The port as a whole is GPL-3.0-or-later: most sources are GPL-2.0-or-later, but the Hunter's Dream network code (`gpu/bbnet/thd`), five files in `src/` and one test are GPL-3.0-or-later. The package's `LICENSE` still held the GPL v2 text.

## What changed

- `launcher/bbport_launcher_win.py`: `RELEASES_API` and `RELEASES_PAGE` point at wanderabyss/sunbros_bblauncher. The update check (`latest_release`), the update download, **Settings > Releases** (`viewRelease`) and the release-notes and changelog links in the update sheet (`openReleaseLink`) are all built from them.
- `run.py`: `RELEASES`, shown when the package is incomplete, points at the new releases page.
- `tests/test_update_download_qml.py`: expects the new addresses.
- `LICENSE` (repository root, new) and `bloodborne_pc/LICENSE`: the GPL v3 text. The GPL v2 text moved to `bloodborne_pc/licenses/GPL-2.0.txt` and `packaging/windows/licenses/GPL-2.0.txt`, so the package's `licenses` folder keeps it.
- `README.md` and `bloodborne_pc/README.md`: links to the new repository, a License section, and the current version in the install examples. The gameplay video is attached to the v4.2.9 release.

## Checked

- The Python suite passes.
- The update API at the new repository answers with the latest release and its zip.
- In the package: `launcher/bbport_launcher_win.py` and `run.py` name the new repository, and `LICENSE` is the GPL v3 text.
- Not checked in game: nothing in the game changed.
