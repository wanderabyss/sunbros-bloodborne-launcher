# 4.2.13 — Issue templates, contributing and security guides (2026-10-30)

Built on 4.2.12. No code changes: the launcher and the game are the same as 4.2.12.

## Why

The repository is about to go public. Bug reports need the details that make them fixable, contributors need to know how to build and test, and security problems need a private way in.

## What changed

- `.github/ISSUE_TEMPLATE/`:
  - `bug_report.yml`: version, graphics card and driver, play mode, what happened, `last_run.log`, settings.
  - `feature_request.yml`.
  - `config.yml`: no blank issues, and questions go to Discussions.
- `CONTRIBUTING.md`: report, build, test, keep it clean, open a pull request.
- `SECURITY.md`: latest release only; report privately with **Report a vulnerability** in the Security tab.
- `README.md`: badges for the latest release, downloads, licence and platform. The version line names only the current release.
- `bloodborne_pc/README.md`: the version paragraph names only the current release.
- `docs/images/social-preview.png`: a 1280 × 640 card for links shared on Discord, Reddit or X. It's set in the repository's Settings, not in the package.

## Checked

- The Python suite passes.
- The public dry run: the leak check is clean, and the issue templates are included.
