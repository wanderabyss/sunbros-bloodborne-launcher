# 4.2.3 — Your PC at a glance in the launcher (2026-10-30)

Built on 4.2.2. Launcher only; no game or renderer changes.

## Home: the rig pill

- `launcher/bbport_rig.py` reads this PC once, on the launcher's existing GPU-check thread (`LauncherBackend._detect_gpu`): the card the GPU check picked (the game's, not an integrated GPU) with its video memory and driver from the display-adapter registry keys, the processor name (registry) and its cores (`GetLogicalProcessorInformationEx`) and threads, and installed memory (`GetPhysicallyInstalledSystemMemory`). No WMI. Video memory is shown as the size the card is sold as (Windows reports an RTX 4090 as 22.5 GiB); NVIDIA drivers as NVIDIA numbers them (621.01).
- `LauncherBackend.rig` adds the display from Qt (resolution in physical pixels, refresh rate); `dlss5Offered` exposes the GPU check's DLSS 5 answer.
- `HomePage.qml`: the pill between the badge and the top-right controls, with new `NavIcon` kinds `gpu`, `cpu` and `memory`. Segments drop from the right when the window is narrow and the pill hides when nothing fits; hover shows a details card, a click keeps it open. Hidden until the GPU check reports, and when it finds no card.
- Tests: `tests/test_launcher_rig.py`.
