# 4.2.11 — Licence and art notes for the public source (2026-10-30)

Built on 4.2.10. No code changes: the launcher and the game are the same as 4.2.10.

## Why

The source is going public as wanderabyss/sunbros_bblauncher. NVIDIA's DLSS runtime files sit in the repository without their licence text beside them, and some launcher art comes from Bloodborne itself.

## What changed

- `bloodborne_pc/nvngx_dlss_310.9.1/NVIDIA-DLSS-LICENSE.txt`: the NVIDIA RTX SDKs licence, beside `nvngx_dlss.dll` and `nvngx_dlssg.dll` (the package already ships it in `licenses`).
- `bloodborne_pc/launcher/assets/README.md`: which launcher art is this project's and which comes from the game (trophy icons, the Bloodborne logo and title font, `ui/home-bg.jpg` and the blurred page backgrounds in `ui/bg`), and how to build with the game's art. The public source leaves those files out; the package still has them. Without them the launcher runs with empty backgrounds and the default font.

## Checked

- The Python suite passes.
- In the public tree without the game's art, the launcher's QML tests pass.
