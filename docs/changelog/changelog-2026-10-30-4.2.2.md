# 4.2.2 — One copy of the version, translations and DLSS model choices (2026-10-30)

Built on 4.2.1. No renderer changes; settings files load as before.

## Version

- The launcher reads `version.txt` at run time (`bbport_launcher_win.py` `_read_version`); the hardcoded `VERSION`, the `HomePage.qml` fallback, the backend's own lookup and `launcher/version.txt` are gone. `scripts/sync_version.py` derives `pyproject.toml`, `uv.lock` and `bloodborne_pc/version.txt` from the Release_Notes.md header.
- The pre-commit hook runs `sync_version.py --stage`, which stages only the files it changed: partial commits of the launcher no longer pick up unrelated edits.
- Test: `tests/test_version_source.py`.

## Release builds

- `scripts/build_dist.py` writes `out/build-stamp.txt`, the git trees of the engine sources (build.sh, gpu, src, third_party, tools, packaging/windows) as they are on disk, committed or not. A different stamp rebuilds, so a merge, a branch switch or an edit no longer ships older binaries; launcher or doc changes don't rebuild, and neither does a commit that leaves the engine sources alone (the commit in the stamp is only a label). `--skip-build` warns when the binaries don't match. Test: `tests/test_build_dist_stamp.py`.
- The zip and `dist/<pkg>` carry no DLSS 5 files and stay the ones to publish. `--no-dlss5` skips it; without the kit (a fresh clone) it is skipped with a note.

## Launcher translations

- `bbport_lang.py` and `bbport_lang_more.py` map each English text to its translation instead of listing translations by position. Every language's lookup table is unchanged. Test: `tests/test_launcher_translations.py` (every language has every text, no leftovers, the same `{}` placeholders).

## Launcher icon

- `launcher/assets/hunter-icon.ico` (the launcher window, its taskbar button, `Bloodborne.exe`, and `Play Bloodborne.exe` through `packaging/windows/play.rc`) is the gold Hunter's Mark from Home (`NavIcon.qml` "huntersmark", `Theme.gold`) on a dark rounded tile, 16 to 256 px. `hunter-icon.png` stays the splash art; the game (`bb-probe.exe`, `bb-probe.rc`) keeps `bloodborne.ico`.

## DLSS model setting

- `bloodborne_pc/scripts/dlss_models.tsv` holds the models, their saved index, NGX preset, labels (English and Russian), menu order and help. `scripts/gen_settings_tables.py` writes `gpu/shim/bbport_dlss_models.h` and `launcher/bbport_dlss_models.py` (both committed), used by `bbport_settings.*`, `bbport_overlay.cpp`, `bbport_nvidia_gpu.h`, the launcher and its backend. Test: `tests/test_settings_tables.py`.
- "Default" reads "Default: the driver's choice" in the launcher and "Default - the driver's choice" in the game (were "Default: driver's choice" and "Default (the driver's choice)").
