# Security

## Supported versions

Only the [latest release](https://github.com/wanderabyss/sunbros-bloodborne-launcher/releases/latest) gets fixes.

## Reporting a vulnerability

Please don't open a public issue. Report it privately from this repository's **Security** tab, with **Report a vulnerability**. Include the version, what an attacker could do, and how to reproduce it.

Areas that matter most: the launcher's update download and install, the online and co-op networking (Hunter's Dream server, BBSC relay, the Windows firewall rule the launcher adds), and anything that reads files from mods or patches.
